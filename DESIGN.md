# Fleet Social design context

Fleet Social preserves CogSend's existing Svelte and Tailwind interface for its internal first release. The app is an operator workspace, with a narrow centered canvas, floating navigation, white rounded cards, stone typography, and restrained semantic status colors. Project ownership and approval appear in the composer where the owner decides what to send. Per-account receipts and uncertain outcome reconciliation appear in Posts where the owner checks delivery.

The product job is to review and account for Fleet project posts without obscuring a possible duplicate. Project and approval controls must stay visible near publish and schedule actions. Published links open the exact destination when known. An uncertain result stays visually distinct from an ordinary failed attempt and offers explicit owner reconciliation.

Keep keyboard labels, clear focus states, touch sized actions, and responsive single column behavior. Use the existing project components and visual tokens; no new UI library or runtime dependency is needed for these controls.
